**Local development note:** The `Invalid prisma.order.findMany()` error on `/admin` happens when your local database has not been migrated to include the `taxId` column. Run `pnpm prisma migrate dev --name add_order_tax_id` (or `pnpm prisma migrate deploy`) using the same `DATABASE_URL` you use for development, then restart `pnpm dev`. Once the migration runs locally the admin dashboard loads normally.
