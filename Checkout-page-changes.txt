Checkout & Stripe Integration Overview
=====================================

Implemented changes
-------------------
- Added a localized `/checkout` page (`app/[locale]/checkout/page.tsx`) with a full Checkout UI via `CheckoutView`.
- Introduced `components/checkout/CheckoutView.tsx` to manage contact, shipping, billing, notes, and the Stripe Elements payment step.
- Created `lib/hooks/useAnonCartImport.ts` so cart data collected while anonymous migrates once upon login (shared with cart & checkout views).
- Updated cart/favorites identity handling (clear on sign-out / identity switch) and wired cart checkout button to redirect to `/account?callbackUrl=/checkout`.
- Added `app/api/checkout/create-payment-intent/route.ts` which validates payloads, computes totals server-side, creates orders, and provisions Stripe PaymentIntents.
- Shared cart total logic via `lib/utils/cart-totals.ts`, reused by cart, checkout, and the new API.
- Introduced Stripe client/server dependencies (`@stripe/react-stripe-js`, `@stripe/stripe-js`, `stripe`).

Environment & configuration
---------------------------
1. Stripe keys (required):

```
STRIPE_SECRET_KEY=sk_test_...
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=pk_test_...
```

2. Optional: adjust currency (`EUR` by default) by setting the `currency` field in the checkout payload if you need another ISO code.

3. Run `pnpm install` after pulling to install the new Stripe packages.

4. (Future) Configure `STRIPE_WEBHOOK_SECRET` and implement `/api/stripe/webhook` to mark orders paid on `payment_intent.succeeded`.

User flow notes
---------------
- Unauthenticated users clicking **Proceed to Checkout** are redirected to account login with a callback to `/checkout`; their local cart snapshot is queued for one-time import post-authentication.
- Authenticated users land on the checkout form, generate a server-side PaymentIntent on first submit, then confirm the payment via Stripe Elements.
- Orders are created with `PaymentStatus.PENDING` and tied to the Stripe PaymentIntent via metadata that embeds contact and address data.
