## 1) HIGH-LEVEL REQUIREMENTS
- Framework: Next.js (App Router), TypeScript, TailwindCSS.
- UI libraries: shadcn/ui, framer-motion, lucide-react. Modern, elegant, responsive, “pleasantly minimal + premium” vibe.
- State: lightweight global store (Zustand) for cart & favorites. Persist to localStorage. Avoid unnecessary rerenders (selectors).
- i18n: Next.js built-in i18n (locales: en, pt; default: en). Support localized copy for nav, banners, headings, product fields (name/desc).
- Age Gate: First visit shows a modal asking if user is 18+. Store consent in localStorage (and cookie) to skip next time. Deny → redirect to a neutral page (e.g., /age-gate-denied).
- Routing:
  - `/` home (hero, categories, featured)
  - `/about`, `/contact`, `/account` (placeholder login/profile), `/cart`, `/favorites`
  - `/licor`, `/aguardente`, `/bebida-espiritosa` list pages with filters/search
  - `/product/[slug]` product detail page (use mock data & images)
  - `/api/...` endpoints (see backend section)
- Navigation:
  - Beautiful desktop menu with animated underline/hover
  - Mobile hamburger menu (slide-in, open/close animations with framer-motion)
- UX:
  - Top free-shipping banner
  - Sticky header (slight blur on scroll), search input, cart/favorites icons with counters
  - Product cards: image, title, price, tags; buttons [Add to Cart] [♡ Favorite]
  - Accessible: alt text, semantic tags, focus states
- Performance:
  - Prefer Server Components for pages/layout where possible
  - Client Components only where state/interaction needed
  - Use `next/image`, responsive sizes, lazy-loading images
  - Avoid prop-drilling; memoize components where appropriate
  - Stable keys & list rendering; defer heavy JS where possible
