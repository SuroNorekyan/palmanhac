Assumptions:
- Postgres remains the primary data source; new migrations expect the database to be migrated before running the app.
- The ADMIN_PASSWORD environment variable will be provided during seeding and never committed in plaintext.
- Two-factor secrets are encrypted with AES-256-GCM using TOTP_ENCRYPTION_KEY; loss of this key invalidates stored secrets.
- Rate limiting is in-memory for now and should be backed by a shared store if we scale horizontally.
- Payment endpoints are mock placeholders and perform no external network calls.
